# UI 界面设计方案

## 1. 设计目标

界面重点不是做成普通后台管理系统，而是做成一个“3D 创作工作台 + 设备仿真器”：

- 用户选择场景后立即看到 3D 预览
- 用户调参数时，同时看到真实圆盘显示效果
- 用户不需要理解极坐标和数据协议，也能完成导出
- 高级用户能查看 360×80 像素、角度片、数据包和链路状态
- 深色高对比界面突出 LED、Bloom 和裸眼 3D 效果

## 2. 主界面布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 顶栏：项目名 / 设备状态 / 仿真模式 / 导出 / 运行                             │
├──────────────┬───────────────────────────────────────┬───────────────────────┤
│ 场景库       │ 3D 编辑器视口                         │ 参数检查器            │
│              │                                       │                       │
│ 20 个场景     │ 旋转物体、灯光、摄像机、动画          │ 场景/相机/材质/动画   │
│ 分类/搜索     │ 播放控制、俯仰角、缩放                 │ 显示/设备/导出         │
│ 缩略图        │                                       │                       │
├──────────────┴───────────────────────────────────────┴───────────────────────┤
│ 时间轴：播放头、关键帧、速度、循环、时间范围                                 │
├──────────────────────────────┬───────────────────────────────────────────────┤
│ 真实设备圆盘预览              │ 数据预览：360 角度 × 80 LED / 链路统计        │
└──────────────────────────────┴───────────────────────────────────────────────┘
```

推荐最小工作分辨率：`1440×900`。

## 3. 顶层导航

左侧可折叠导航栏：

- 工作台
- 场景库
- 设备管理
- 批量导出
- 历史项目
- 设置

当前主流程为“工作台”，其他页面作为二级模块。

## 4. 主工作台页面

### 4.1 顶栏

左侧：

- 项目名称，可重命名
- 自动保存状态
- 当前场景名称和版本

中间/右侧：

- `编辑` / `真实设备` / `数据` 三种视图切换
- 设备连接状态：未连接、连接中、已就绪、播放中、错误
- 帧率：编辑器帧率 / 设备内容帧率
- 主要按钮：`保存`、`导出`、`上传并运行`

### 4.2 左侧场景库

使用 Ant Design `Tabs + Card + List`：

分类：

- 节庆
- 商品
- 人物/角色
- 文字/数字
- 抽象/科技
- 我的导入

每个场景卡片包含：

- 缩略图
- 场景名
- 类型标签
- 预计帧数
- 是否含有用户素材
- “添加到项目”按钮

搜索和过滤：

- 关键词搜索
- 内置/我的素材
- 节庆/商品/抽象
- 是否支持设备实时预览

### 4.3 中央 3D 编辑器

用户已确认的关键布局约束：

- 3D 显示区域必须保持 1:1 正方形。
- 正方形内提供可开关的圆形设备显示框，92% 直径区域用于模拟实际圆盘范围。
- 圆框外区域需要压暗，方便判断设备实际可见区域。
- 左侧场景库、右侧参数检查器和下方预览区域必须可以独立显示或隐藏。
- 任意面板隐藏后，中央正方形视口应自动重新计算并尽可能放大。

中央区域负责“好看、可调、所见即所得”：

- React Three Fiber 画布
- 鼠标左键旋转对象或摄像机
- 鼠标中键平移
- 鼠标滚轮缩放
- 可视化的相机角度、焦距、距离
- 灯光、材质、网格、阴影开关
- 物体选中后的 Transform Controls
- 播放/暂停/停止/上一帧/下一帧
- 当前时间、总时长、循环模式
- 渲染质量：草稿/标准/高质量
- 编辑视角与设备投影视角切换

画布角落显示：

- 当前动画时间
- 实际设备基础内容帧率：约 16.67 fps
- 当前输出分辨率：360×80
- 是否启用 Bloom、运动模糊、AO

### 4.4 右侧参数检查器

使用 Ant Design `Tabs`：

#### 场景

- 场景选择
- 模型/贴图路径
- 背景颜色
- 环境光强度
- 地面/阴影
- 资源许可证状态

#### 摄像机

- 水平角度
- 垂直角度
- 镜头距离
- 焦距/视场角
- 透视/正交
- 自动巡航
- 设备投影裁切

#### 材质

- 基础色
- 金属度
- 粗糙度
- 自发光
- 透明度和折射
- 边缘光
- 颜色校正

#### 动画

- 播放速率 `0.1x - 4x`
- 旋转方向
- 旋转角度范围
- 循环方式
- 关键帧列表
- 帧插值方式

#### 显示效果

- Bloom
- 辉光
- 阴影
- 景深
- 运动模糊
- 对比度和饱和度
- 径向边缘增强
- 低亮度抖动

#### 设备

- 设备 IP 输入框
- TCP 端口固定为 5000
- 手动连接/断开按钮
- 上传模式
- 预缓冲帧数
- 亮度上限
- Gamma 模式
- 0° 校准
- 方向翻转
- 链路统计

#### 导出

- `.fan360` 单圈/多圈帧
- GIF/MP4/PNG 序列预览
- 项目 JSON
- 打包所有素材
- 导出范围和命名规则

### 4.5 底部时间轴

使用 `Timeline + Slider + Select`：

- 当前播放头
- 关键帧标记
- 场景动画时长
- 播放范围
- 帧率提示
- 循环模式
- 当前动作轨道
- 可折叠的动画曲线编辑区域

第一版先实现直线时间轴和关键帧标记，曲线编辑器放到第二阶段。

### 4.6 真实设备圆盘预览

这是本项目的核心差异化组件，必须和普通 3D 编辑器并列展示。

显示内容：

- 实际圆形外轮廓
- 360 个角度片的方向
- 80 个径向 LED 的采样环
- 当前角度扫描线
- 转子旋转方向
- 边缘黑区/未覆盖区域
- 亮度、Gamma、色彩量化后的结果
- 与编辑器画面的差异对比

按钮：

- 暂停/播放
- 显示扫描线
- 显示采样网格
- 显示原始 3D 和真实设备叠加对比
- 单圈/连续播放

### 4.7 数据预览面板

使用表格和图像：

- 当前角度片编号
- 当前时间片
- 80 个 LED 的 `[亮度,R,G,B]`
- 当前角度片 320 B 十六进制
- 一帧总数据量 115,200 B
- 链路使用率
- 丢包/CRC 错误
- 一帧上传耗时
- 设备缓冲区状态

普通用户默认折叠，开发者模式下显示。

## 7. 视觉风格

- 背景：深灰/黑，避免纯黑导致边界丢失
- 主色：青色/紫色渐变，强调 LED 科技感
- 强调色：青蓝、洋红、暖橙
- 面板：半透明深色玻璃质感，但不要把文字对比度做低
- 按钮：主操作为高亮渐变，危险操作使用红色
- 圆盘预览区域：黑底 + 微弱径向网格
- 重要数值：等宽字体
- 不使用大量装饰性动画，动画只用于表达状态和实时数据

## 8. 关键交互流程

### 新用户流程

```text
选择场景
  → 3D 预览
  → 调整镜头/动画/效果
  → 查看真实设备圆盘预览
  → 输入设备 IP
  → 手动点击连接
  → 整帧上传（同步期间暂停显示刷新）
  → 校验完成后恢复显示
```

### 高级流程

```text
选择场景
  → 打开设备投影视图
  → 查看 360×80 采样结果
  → 调整 Gamma、亮度、抖动、径向增强
  → 查看数据包和链路占用
  → 导出 `.fan360`
```

## 9. 响应式策略

- 主工作台以桌面大屏为第一优先级
- 窗口较窄时：
  - 左场景库折叠为抽屉
  - 右参数面板折叠为抽屉
  - 底部数据预览可隐藏
  - 中央 3D 视口保持最小可用尺寸
- 不建议在第一版做手机布局，因为核心任务是桌面编辑和设备调试

## 10. UI 验收标准

- 新用户能在 3 分钟内完成“选场景 → 调参数 → 看到设备效果 → 导出”
- 3D 编辑和真实设备预览可以同屏对照
- 设备连接异常不会阻塞编辑器
- 360×80 数据、角度片、链路状态对开发者可见
- 所有关键参数都有默认值、范围限制和恢复默认功能
- 关键操作都有撤销或确认机制
- UI 在 1440×900 和 1920×1080 下均可正常使用
