## 第一版最小但完整的目标

第一版不要缩减为只有 UI 的空壳，至少应形成以下闭环：

```text
选择场景
  → 3D 实时预览
  → 调整为圆盘效果
  → 生成 360×80 数据
  → 导出 .fan360
  → 模拟设备回放
  → 连接真实设备播放
```

第一版推荐先完成 3 个高质量场景，再逐步补齐 20 个场景；但产品的最终交付仍以 20 个场景和完整设备链为目标。
