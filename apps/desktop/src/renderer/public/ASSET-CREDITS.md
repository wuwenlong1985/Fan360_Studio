# Scene assets

These assets ship locally with Fan360 Studio. No network requests are needed to display them.

- `models/portrait/`: **Marble Bust 01**, Rico Cilliers, Poly Haven. CC0 1.0.
  Source: https://polyhaven.com/a/marble_bust_01
  License: https://polyhaven.com/license
  Original 2K glTF and all dependencies; texture/bin MD5 checks verified against the Poly Haven API.
  The application centers and scales the model; source geometry and textures are unchanged.
- `models/astronaut.glb`: **Astronaut**, Poly, CC BY 2.0.
  Distributed by the model-viewer project: https://modelviewer.dev/shared-assets/models/Astronaut.glb
  Attribution and license evidence: https://modelviewer.dev/examples/scenegraph/
  Original attribution: https://poly.google.com/view/dLHpzNdygsg
  License: https://creativecommons.org/licenses/by/2.0/
  The application centers and scales the model; source geometry and textures are unchanged.
- `textures/earth-day.jpg`: Earth texture distributed with the Three.js example assets.
  Source: https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/earth_atmos_2048.jpg
  Distribution license: Three.js MIT license, included in `textures/LICENSE-threejs.txt`.
- Studio environment and Bunny: bundled `@pmndrs/assets` v1.7.0, CC0 1.0.
  Source: https://github.com/pmndrs/assets
- Strawberry, rose, gift box, faceted diamond and car: procedural geometry created for this project.
- `draco/`: Google Draco decoder distributed with Three.js, Apache-2.0. The license is included in `draco/LICENSE`.
  Source: https://github.com/google/draco
